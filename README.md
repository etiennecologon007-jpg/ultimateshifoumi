# Ultimate Shifoumi

Ultimate Shifoumi est un jeu de pierre-feuille-ciseaux amélioré, pensé pour offrir une expérience plus dynamique, plus stratégique et plus amusante que le classique duel 1v1.

Le but du jeu est simple : battre l’adversaire en choisissant le bon coup, mais avec des mécanismes supplémentaires, des bonus, des niveaux et des modes de jeu qui rendent chaque partie plus intense.

---

## 🎮 Description

Dans Ultimate Shifoumi, les joueurs s’affrontent dans une bataille de choix rapides et de stratégies.  
Le jeu reprend les règles de base du Shifoumi :

- Pierre bat Ciseaux
- Ciseaux bat Papier
- Papier bat Pierre

Mais il ajoute une dimension plus “ultimate” :
- niveaux progressifs,
- différents modes de jeu,
- animations ou effets visuels,
- score, partie rapide, mode solo ou multijoueur,
- bonus/atouts selon les variantes du jeu.

---

## ✨ Fonctionnalités

- Interface simple et fluide
- Système de score
- Plusieurs rounds
- Modes solo / IA / multijoueur
- Animations visuelles
- Détection du gagnant à chaque manche
- Possibilité d’ajouter des règles avancées ou des pouvoirs spéciaux
- Responsive design (si projet web)

---

## 🕹️ Règles du jeu

Chaque joueur choisit une option :

- Pierre
- Papier
- Ciseaux

Le gagnant est déterminé selon la règle classique :

- Pierre > Ciseaux
- Ciseaux > Papier
- Papier > Pierre

En mode “Ultimate”, il peut être ajouté :
- un système de combo,
- des bonus aléatoires,
- des rounds à élimination,
- ou des règles bonus personnalisées.
