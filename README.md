# Ultimate Shifoumi

Jeu de pierre-feuille-ciseaux (Shifoumi) réalisé en HTML, CSS et JavaScript.

Le joueur choisit entre pierre, feuille et ciseau, puis l'ordinateur joue au hasard. Le jeu affiche ensuite le résultat et met à jour les scores en temps réel.

## 🚀 Démo

https://deniscologon-svg.github.io/ultimateshifoumi/

## ✨ Fonctionnalités

- Choix du joueur : pierre, feuille, ciseau
- Jeu contre l'IA
- Décompte des victoires, défaites et égalités
- Interface simple et responsive
- Design modernisé avec icônes et typographie

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript Vanilla

## ▶️ Lancer le projet

Vous pouvez soit :

1. Ouvrir directement `index.html` dans votre navigateur.
2. Servir le dossier localement avec un petit serveur, par exemple :

```bash
python -m http.server 8000
```

Puis ouvrir : `http://localhost:8000`

## 📌 Objectif

Ce projet est un petit jeu web ludique pour pratiquer la logique JavaScript et le développement front-end en mode statique.
